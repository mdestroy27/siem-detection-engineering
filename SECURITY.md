# Security Policy

## Scope

This repository contains independent cybersecurity detection engineering examples, synthetic datasets, documentation and automation scripts.

It is not a production security monitoring service.

## Reporting Security Issues

If you identify a security vulnerability in the repository's code or automation scripts, please report it privately to the repository maintainer rather than publishing exploit details in a public issue.

Include:

- A description of the issue.
- Potential impact.
- Steps to reproduce, where appropriate.
- Suggested remediation, if known.

## Data Protection

This repository must not contain:

- Production security logs.
- Customer or employee information.
- Credentials, API keys or tokens.
- Confidential employer detection logic.
- Internal infrastructure details.

## Responsible Use

All examples are intended for legitimate security engineering, defensive monitoring, research and education.
